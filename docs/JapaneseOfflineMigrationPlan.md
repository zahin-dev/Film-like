# 日本語・ローカル完結版への調査と移行計画

調査日: 2026-07-26
対象: `zahin-dev/Film-like`
実装ブランチ: `feat/japanese-offline-version`

## 1. 修正前の調査結果

### 外部APIとキー

| 外部依存 | 用途 | 認証・制約 | 修正前の影響 |
| --- | --- | --- | --- |
| TMDB API | 映画検索、基本情報、詳細、クレジット、配信サービス | `TMDB_READ_ACCESS_TOKEN`が必須 | キーまたはネットワークがないと検索・詳細・履歴追加が動作しない |
| TMDB画像ホスト | ポスター表示 | TMDB応答の画像パス | 外部停止時に画像を取得できない |
| Mistral Chat Completions API | 推薦候補と理由の生成 | `MISTRAL_API_KEY`。未設定時は503 | 推薦がクラウドLLMと無料枠・課金条件に依存 |

設定クラスには`TMDB_READ_ACCESS_TOKEN`、`MISTRAL_API_KEY`、`MISTRAL_MODEL`、`MISTRAL_API_BASE_URL`がありました。CIはダミーのTMDBトークンを設定していました。

### 映画情報とDB

- `tmdb_client.py`が`/search/movie`、`/movie/{id}`、`/watch/providers`へ直接接続。
- 検索・詳細の言語は`en-US`。
- 配信地域の既定値はフランス`FR`。
- ローカルの`films`テーブルは存在しなかった。
- `viewing_history_entries`は`tmdb_id`だけを映画識別子として保存。
- 以前に存在した履歴のタイトル・ポスター列は、TMDBを唯一の情報源にするマイグレーションで削除済み。
- 履歴一覧の表示時にもTMDBへ並列接続していた。

### 推薦と分析

- 推薦はMistralへ英語プロンプトを送信し、返された英語理由を表示。
- 候補はTMDB検索で照合していた。
- APIキー未設定時は推薦APIが503。
- 視聴傾向の集計自体は、ユーザーが選んだタグを数える決定的なローカル処理だった。

### 日本語化前の表示

フロントエンドのナビゲーション、認証、検索、詳細、履歴、分析、推薦、プロフィール、ローディング、空状態、エラー、再試行、確認、`aria-label`、画像代替文、ページタイトルは英語でした。

バックエンドでは認証、404、409、503、推薦失敗、バリデーションのユーザー向けメッセージが英語でした。FastAPIの説明もTMDB連携を前提にしていました。

### タグ、気分、評価

- タグの`name`と`description`は50件すべて英語。
- タグ名が一意な表示値を兼ね、安定した内部キーと日本語表示名が分離されていなかった。
- 気分コードは`relaxed`など8種類で、画面表示も英語。
- 評価はPostgreSQL Enumに`Platinum`から`Trash`までの英語値を保存。

### 地域・日時

- HTMLは`lang="en"`。
- フロントエンドの日付は英語ロケール。
- TMDBの言語は`en-US`、配信地域は`FR`。
- アプリのタイムゾーン設定は明示されていなかった。

### テストとCI

- 映画テストはTMDBクライアントを`AsyncMock`で置換。
- 推薦テストはMistral出力とTMDB検索をモック。
- 外部APIとの契約は検証していたが、APIなしで機能する経路は存在しなかった。
- CIにダミーTMDBトークンがあった。
- 公開文監査は日本語文字を拒否し、英語文書を強制する逆向きの検査だった。
- マイグレーションの旧`tmdb_id`実データ移行テストはなかった。

### 公開文書

README、DevelopmentProcess、Verification、Architecture、ClassDiagram、ERDiagram、SequenceDiagramsが英語で、TMDBとMistralを現在の主要構成として説明していました。Swaggerのタイトル・説明も英語でした。

## 2. 採用した移行方針

### ローカル映画カタログ

- `film_data_sources`: 出典、ライセンス、商用利用、再配布、取得日、日本語情報、更新方法。
- `films`: ローカルID、出典側ID、任意の旧TMDB ID、日本語メタデータ、配信情報、検索文字列、推薦気分。
- `FilmCatalogProvider`プロトコルと`LocalFilmCatalogProvider`を追加。
- 主要経路はローカルプロバイダーだけを使用。
- 外部クラウドアダプターは削除。

### 後方互換

- 旧`tmdb_id`は削除しない。
- マイグレーション時に、既存の異なる`tmdb_id`ごとに`legacy-tmdb`出典の照合用映画を作る。
- 視聴記録へ`film_id`を追加して照合用映画へ関連付ける。
- `POST /films/log`は新`film_id`に加えて旧`tmdb_id`も受理する。
- `/films/by-tmdb/{tmdb_id}`と削除用互換経路を用意する。
- ローカル専用映画の履歴がある状態のダウングレードは、識別情報を失うため明示的に停止する。

### タグと評価

- タグへ安定した`key`、`display_name_ja`、`description_ja`を追加。
- 既存の英語`name`は照合用に保持。
- 既知の50タグをマイグレーションで日本語表示へ対応付け、シードで自然な説明へ更新。
- 評価の保存値は互換性のため維持し、APIと画面で日本語ラベルを返す。

### 推薦

- 外部AIを廃止。
- 気分一致、ジャンル一致、過去のタグ頻度、直近5件のジャンルを加点。
- 視聴済みIDと重複を除外。
- 点数と安定した項目で決定的に整列。
- 候補不足時は未視聴候補で補い、日本語メッセージを返す。
- 推薦理由は日本語テンプレートで生成。

### 日本向け設定

- 言語: `ja-JP`
- 地域: `JP`
- タイムゾーン: `Asia/Tokyo`
- HTML: `lang="ja"`
- 配信情報: ローカル編集された日本向けデータだけを表示し、更新日がある場合だけ明示。

### データの権利

大規模データソースの自動取得やスクレイピングは行わない。代わりに次を実装する。

1. 第三者ポスターを含まない12件の小規模日本語デモ
2. ローカルJSONインポート
3. 出典マニフェスト
4. 外部画像URLを拒否する検証
5. ライセンス確認手順

## 4. 完了判定

完了時は次を実行する。

```bash
docker compose config
docker compose up -d
cd backend
python -m pytest -q
python -m pytest --cov=app
cd ../frontend
npm ci
npm run test
npm run lint
npm run build
```

Dockerデーモンやポートなど実行環境に依存する失敗は、コード不具合と分けて[Verification.md](Verification.md)へ記録する。
